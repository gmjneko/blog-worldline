最近有种很奇怪的感觉，AI 的迅速发展与 Agent 的出现让我得以推进远超我能力范围内规模的项目，从结果看来似乎都不错，但我好像很久没有真正学到东西了。

以前我一直坚信边做边学，写代码、debug，被一个问题卡住，顺着它往下挖，慢慢就懂了。

现在卡住了就交给 agent，然后我就去做其他的事情，回来时问题已经解决，看着AI给出的结论我似乎大概能懂是怎么回事，但是有没有真正弄懂了的实感。最后代码能跑，测试通过，但好多状态机我没理清、好多细节我也不了解，甚至还得回头读懂“我做的项目”的代码。但我自己也越来越习惯这种轻松得到结果的感觉，不愿意静下心啃东西了。

我当然不想回到所有代码都得手写的时代，但开始意识到，过去那套靠项目顺便学习的方法，现在可能真的不够了。

LLM 和 Agent 的出现迅速摧毁了传统的软件工程、摧毁了过去计算机培养体系的一切，却又没有提供一种恰当的方式来帮助人们学习。

我时常在想有些时间得专门留给自己，学基础、手操、把一个复杂问题想到底，不然项目越做越多，我还是停在什么都懂一点、什么都没懂透的地方。
